#### portfólio pessoal criado com:
- [Next.JS](https://nextjs.org/learn) (dos mesmos criadores do Vercel, por isso possuem uma ótima conexão entre si)
- [Talwind CSS](https://vercel.com/ravvtici) (alta conectividade com Next.JS)
- [Vercel](https://vercel.com) (responsável por hostear o site)


#### instalação local (archlinux):
```
sudo pacman -S pnpm
pnpm i # instala pacotes do projeto
pnpm dev # roda no localhost:3000
```
